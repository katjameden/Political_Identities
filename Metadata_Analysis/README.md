# Metadata Analysis

- [Sample](./Sample/): Sample data, available to run the metadata analysis (for demonstration purposes). 
- [Notebooks](./Notebooks/): Jupyter notebooks containing the code and descriptions of analytical patterns. The reported analysis outputs are based on the full dataset, but the notebooks can also be run on the sample dataset for demonstration purposes.
- [Results](./Results/): Contains the figures generated during the analysis, including Plotly visualizations that are stored separately due to GitHub's limited support for rendering them within Jupyter notebooks.
